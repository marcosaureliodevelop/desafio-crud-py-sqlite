# Desafio para construir um CRUD em Python e Sqlite 3

### Visão Geral
Este projeto consiste em um desafio em criar um CURD com python. Ministrado pelo professor Cloves Rocha na cadeira de Lógica de Programação do curso técnico em desenvolvimento de sistemas.

---

### Escopo do Desafio

- Criar um CRUD completo
- Gerenciar a persistência dos dados corretamente
- Sistema executável na linha de comando (sem UI)

---

### Tecnologias

- Python
- SQlite3
